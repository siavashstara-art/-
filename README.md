# آموزش بازاریابی اصناف — آموزش بازاریابی (فروشیار / ForoshYar)

**اکوسیستم آفرینش · شهر نوآوران AbleCity · توانا · بندستوانا**  
**نسخه معماری:** `Domain Core v4.0 (Locked & Hardened)`

---

## معرفی پروژه (آموزش بازاریابی اصناف)

این مخزن شامل سامانه جامع **آموزش بازاریابی اصناف (فروشیار — ForoshYar)** است؛ یک دنیای شبیه‌سازی‌شده فروش (Simulated Sales World) با معماری **آفلاین‌محور (Offline-First)** برای آموزش و تمرین، و **آزمون و صدور گواهینامه آنلاین و امن** برای بازاریابان، ویزیتورها و سفیران فروش ۷ محصول تخصصی اکوسیستم آفرینش:

1. **دکورمیت (`DECORMATE`)** — تجسم سه‌بعدی متریال، کاشی، سرامیک و پارکت در فضای مشتری
2. **اسلب‌میت (`SLABMATE`)** — مدیریت موجودی و نمایش دیجیتال بوک‌مچ اسلب‌های سنگ و سرامیک
3. **سالن‌میت (`SALONMATE`)** — اتوماسیون نوبت‌دهی، وفادارسازی و تسویه لاین‌های زیبایی
4. **اتوبارتر (`AUTOBARTER`)** — پلتفرم هوشمند تهاتر چندجانبه خودرو و دارایی
5. **تانارا (`TANARA`)** — سامانه پایش سلامت، توانبخشی و توانمندسازی (توانا / بندستوانا)
6. **طلایار (`TALAYAR`)** — محاسبه آنی مظنه، اجرت و ویترین هوشمند طلا و جواهر
7. **ایونت‌میت (`EVENTMATE`)** — مدیریت هوشمند غرفه‌های نمایشگاهی و ثبت آنی سرنخ‌ها

---

## ویژگی‌های کلیدی معماری (Domain Core v4.0 + Hardening Patch)

- **تفکیک سطح عمومی از گواهینامه محصول:** سطح عمومی سفیر (`A++`, `A+`, `A`, `B`, `C`) از چرخه گواهینامه مستقل هر محصول جداست.
- **پشتیبانی همزمان چندمحصولی (Multi-Product):** هر سفیر می‌تواند به صورت مستقل در هر یک از ۷ محصول وضعیت متفاوتی داشته باشد (`NOT_STARTED`, `TRAINING`, `EXAM_FAILED`, `EXAM_PASSED`, `SIMULATION_FAILED`, `FIELD_EVALUATION`, `CERTIFIED`, `SUSPENDED`).
- **مرز امنیتی فروش میدانی (`authorizeFieldSales`):** بررسی ۱۲ شرط امنیتی و مالکیت (`ambassador_id`, `tenant_id`, `product_id`) پیش از اجازه ثبت فروش یا محاسبه کمیسیون.
- **ایمنی تراکنش و RLS (`executeSecureRlsTransaction`):** چرخه کامل `BEGIN` → `set_config` → اجرای کنترلر → `COMMIT` / `ROLLBACK` → آزادسازی کلاینت دقیقاً یک بار.
- **اعتبارسنجی سخت‌گیرانه کمیسیون (`calculateStrictCommission`):** رد صریح `saleType` نامعتبر یا نرخ‌های غیرمتناهی با `DomainError` بدون Fallback پنهان.

```bash
npx tsx src/domain/core.test.ts
```

## اتوماسیون ساخت APK و AAB در GitHub Actions

فایل `.github/workflows/android-apk-aab-release.yml` به صورت خودکار در هر Push یا انتشار تگ نسخه (`v*.*.*`):
1. تست‌های امنیتی و واحد `Domain Core v4.0` را اجرا می‌کند.
2. باندل وب آفلاین‌محور را بیلد می‌گیرد.
3. خروجی اندروید را با Gradle امضا کرده و فایل‌های `.apk` و `.aab` را در **GitHub Releases** منتشر می‌کند.
